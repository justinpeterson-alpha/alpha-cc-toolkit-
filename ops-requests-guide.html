How to use it

Ops Requests

One place to submit facilities, IT, or supply requests. Every new request DMs the admin on Slack, and taskers without logins can check off jobs from a public list.

Video walkthrough coming soon The Loom will drop in right here — the steps below work in the meantime.

Submitting a request

  1. Sign in with your @alpha.school Google accountRequired to submit or track a request.
  2. Pick a categoryFacilities, IT, Supplies, or General. Facilities asks for a location; IT asks which device or system is affected.
  3. Submit — the admin is notified instantlyA Slack DM goes out the moment your request comes in, so nothing sits unseen.
  4. Track it on My RequestsStatus moves from Submitted → In Progress → Done as it's worked.

For admins

  1. Triage everything from one Admin pageEvery request in one list, with a status dropdown right on each card — no separate tool needed.

For taskers (no login needed)

  1. Open the public Tasker Job List linkNo Slack account or Google sign-in required — this is a separate, public URL from the main app.
  2. See every open job with photosOnly requests in the Tasker category show here, and only the ones still open.
  3. Tap "Mark done" yourselfNo need to loop back through a coordinator once the job's finished.
  4. Need a paper copy?Use the Print / Save as PDF button right on the list.
Note: the Tasker Job List is public by design — share that specific link with taskers, not the main sign-in page, since they don't need (or have) Alpha accounts.
